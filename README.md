## ⚰️ Requirements

- [mpd](https://mpd.readthedocs.io/en/stable/user.html)
  - [Setup guide](https://github.com/kexiku/lespace/blob/main/la%20Voie%20Nerd%C3%A9e/mpd.md)
  - [Ready-made config for your lazy butt](https://github.com/kexiku/dotfiles/blob/main/mpd/.config/mpd/mpd.conf)
- [rmpc](https://rmpc.mierak.dev/installation/#installation-methods)

### Optional

- [kitty](https://sw.kovidgoyal.net/kitty)
- [Bliss theme](https://github.com/ejohnso49/bliss-kitty-theme)
- [Lilex Nerd Font](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/Lilex.zip)

## 💀 Installation

- Download the latest release
- Put the `config.ron` file and the `themes` directory into your rmpc's config location
- Embrace the darkness
